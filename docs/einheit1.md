# Einheit 1 – Fragen

## 1. Was ist der Unterschied zwischen Capacitor und Cordova?
Beide machen es möglich, eine Web-App auch als Handy-App zu benutzen. Capacitor ist aber neuer und wird bei Ionic inzwischen eher verwendet. Cordova ist die ältere Variante.

## 2. Was macht ein ORM wie Sequelize, und wofür braucht man zusätzlich die sequelize-cli?
Sequelize hilft dabei, mit einer SQL-Datenbank über JavaScript zu arbeiten — man muss nicht jedes SQL-Statement selbst schreiben. Die sequelize-cli braucht man dann zB für Models und Migrationen.

## 3. Was unterscheidet npm install von npx beim Ausführen eines Pakets?
Mit `npm install` installiert man ein Paket. Mit `npx` kann man ein Paket direkt ausführen, ohne es extra global installieren zu müssen.

## 4. Was ist REST, und warum passt das Konzept zu einer Client-Server-Architektur wie Ionic-App und Node-Backend?
REST ist eine Art, wie Client und Server über HTTP miteinander kommunizieren. Die Ionic-App schickt dabei Anfragen an das Node-Backend und bekommt Daten zurück, zum Beispiel über GET, POST, PUT oder DELETE.
